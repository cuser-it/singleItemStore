# 易支付配置说明

## 一、易支付 V1 文档
- 官方文档：https://pay.yunvix.com/doc_old.html#pay1

## 二、配置步骤

### 1. 环境变量配置（`.env` 文件）

```env
EPAY_MERCHANT_ID=1000
EPAY_MERCHANT_SECRET=NE5UWjh0NzQ3NWRKNHRYdFc0akFKREplRHR2ZEo4NFQ=
EPAY_GATEWAY_URL=https://pay.yunvix.com/submit.php
EPAY_NOTIFY_URL=http://103.236.76.222:3001/api/payment/epay/notify
EPAY_RETURN_URL=http://103.236.76.222:5173/payment/return
```

**字段说明：**
- `EPAY_MERCHANT_ID`：易支付商户号（从易支付后台获取）
- `EPAY_MERCHANT_SECRET`：易支付商户密钥（用于 MD5 签名）
- `EPAY_GATEWAY_URL`：易支付网关地址，**必须是 `https://pay.yunvix.com/submit.php`**
- `EPAY_NOTIFY_URL`：异步回调地址（易支付服务器POST到你的服务器）
- `EPAY_RETURN_URL`：同步返回地址（用户支付完成后跳转）

### 2. 后台管理界面配置

登录后台管理系统 → 支付预设 → 填写以下信息：

- **网关地址**：`https://pay.yunvix.com/submit.php`
- **商户ID**：`1000`（你的商户号）
- **商户密钥**：`NE5UWjh0NzQ3NWRKNHRYdFc0akFKREplRHR2ZEo4NFQ=`
- **异步回调地址**：`http://103.236.76.222:3001/api/payment/epay/notify`
- **同步返回地址**：`http://103.236.76.222:5173/payment/return`
- **支付方式**：勾选「支付宝」和「微信支付」

**⚠️ 重要提示：**
1. 回调地址和返回地址必须是**完整的URL**（包含协议和域名）
2. 如果是本地测试，域名部分填写 `http://103.236.76.222` + 端口
3. 如果部署到线上，域名部分填写你的实际域名（如 `https://shop.example.com`）

### 3. 支付方式调用值

根据易支付文档，`type` 参数的调用值为：

| 支付方式 | 调用值  |
|---------|---------|
| 支付宝   | `alipay` |
| 微信支付 | `wxpay`  |

前端创建订单时，`paymentChannel` 字段使用这些调用值。

## 三、支付流程

### 1. 创建订单
前端调用 `POST /api/public/orders`，传入：
```json
{
  "skuId": 1,
  "quantity": 1,
  "recipientName": "张三",
  "phone": "13900139000",
  "address": "北京市朝阳区xxx",
  "paymentChannel": "alipay"
}
```

### 2. 获取支付URL
后端返回：
```json
{
  "order": { ... },
  "paymentUrl": "https://pay.yunvix.com/submit.php?pid=1000&type=alipay&...",
  "params": { ... }
}
```

### 3. 跳转支付
前端使用 `window.open(paymentUrl, '_blank')` 打开支付页面

### 4. 支付完成
- **异步回调**：易支付服务器 POST 到 `notifyUrl`，后端验签并更新订单状态
- **同步返回**：用户支付完成后跳转到 `returnUrl`，前端展示支付结果

## 四、签名算法

符合易支付文档的 MD5 签名算法：

1. 排除 `sign` 和 `sign_type` 参数
2. 过滤空值参数
3. 按参数名 ASCII 升序排序
4. 拼接成 `key1=value1&key2=value2` 格式
5. 后面加上商户密钥
6. MD5 加密并转小写

**示例：**
```
原始参数：
{
  pid: "1000",
  type: "alipay",
  out_trade_no: "SO20260903001001ADC4",
  money: "99.00",
  ...
}

排序并拼接：
money=99.00&name=单盒体验装&notify_url=...&out_trade_no=SO20260903001001ADC4&pid=1000&return_url=...&type=alipay

加上密钥：
money=99.00&name=单盒体验装&...&type=alipayNE5UWjh0NzQ3NWRKNHRYdFc0akFKREplRHR2ZEo4NFQ=

MD5 加密：
72719bc7c119d7f16e7ad7baa7518b9f
```

## 六、常见问题

### Q1: 为什么保存后刷新页面还是显示"未配置"？

**A:** 这是之前的 bug，已在 commit `999b004` 中修复。问题原因是后端返回的 `enabledChannels` 字段为 `undefined`，导致前端执行 `.join()` 时崩溃白屏。

### Q2: 回调地址和返回地址填什么？

**A:** 
- **回调地址**（notifyUrl）：必须是完整 URL，易支付服务器会 POST 到这个地址
- **返回地址**（returnUrl）：必须是完整 URL，用户支付完成后浏览器会跳转到这个地址

**本地测试示例：**
- 回调地址：`http://103.236.76.222:3001/api/payment/epay/notify`
- 返回地址：`http://103.236.76.222:5173/payment/return`

**生产环境示例：**
- 回调地址：`https://shop.example.com/api/payment/epay/notify`
- 返回地址：`https://shop.example.com/payment/return`

### Q3: 商户密钥在哪里获取？

**A:** 登录易支付商户后台，在「账户设置」或「密钥管理」中查看。注意：这是一个字符串密钥，不是 RSA 私钥。

### Q4: 支付方式的调用值是什么？

**A:** 根据易支付文档：
- 支付宝：`alipay`
- 微信支付：`wxpay`

前端创建订单时使用这些值作为 `paymentChannel`。
